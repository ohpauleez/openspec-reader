OpenSpec Reader

Local Markdown. Structured specs. A quieter reading experience.

Reading local files

Open a Markdown document or .als, .java, or .jml source file using its file:///… URL. The reader keeps the original URL and resolves links and images relative to the file.

Firefox must display these files as text instead of downloading them. On Linux, see the MIME setup instructions in the project README, including the als, java, and jml extensions.

Optional website access

HTTP(S) documents are supported when you grant access to their origin from the extension popup. Only text Markdown documents are rendered.

Reading state

Up to 40 documents are remembered locally. Source text is never stored in reading state.
